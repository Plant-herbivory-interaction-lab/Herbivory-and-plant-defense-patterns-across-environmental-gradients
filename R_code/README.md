# Folder contents
**Table 1** Table of the files and folder descriptions.

| File/folder name | Description |
|-----------|----------|
|Defense_by_traits_Graphs_and_Qs_March_2025.R| Contains code regarding the final analysis and presentation of the data. This code depends on the **Prep_data_for_all_analysis.R** and **Psem_graphing.R** files. |                       
 | Functions_to_extract_variables_from_GEE.R| Functions used to extract various gradient data from google earth engine. |
 | Google_Engine_init.R | Provides code to initialize the rgee package to interact with google earth engine. |              
 | Import_garden_2023.R | Prepares the raw herbivory and plant defense trait garden data of 2023 into usable data for the final data analysis. |                       
 | Import-gradients.R | Imports the gradient data using the functions in **Functions_to_extract_variables_from_GEE.R** file. |                     
 | Maps.R | Code to produce the maps of the manuscript. |                                  
 | Old_code | Folder that includes the code no longer used in this manuscript. |                                  
| Prep_data_for_all_analysis.R | Combines various tables in the database for final analysis. |               
| Psem_graphing.R | Graphs the structural equation model paths. |                          
| Table.R | Produces a statistical results table in PDF format. |
